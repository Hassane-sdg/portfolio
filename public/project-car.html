🚗 Contrôle de Voiture via ESP32

Système de contrôle à distance d'un véhicule miniature utilisant l'ESP32 avec interface de contrôle personnalisée et retour vidéo en temps réel.

Statut : ✓ Fonctionnel

📸 Galerie du Projet

🎯 Objectifs du Projet

  • ✓ Concevoir un système de contrôle à distance low-cost
  • ✓ Implémenter la communication WiFi avec ESP32
  • ✓ Développer une interface de commande intuitive
  • ✓ Intégrer un retour vidéo en temps réel
  • ✓ Tester les algorithmes de navigation autonome

⚙️ Spécifications Techniques

  • Microcontrôleur : ESP32 (WiFi, Bluetooth)
  • Capteurs : Caméra OV2640, capteurs de distance ultrasonic
  • Moteurs : 2 moteurs DC avec contrôle PWM
  • Alimentation : Batterie LiPo 7.4V
  • Communication : WiFi 2.4GHz, protocole MQTT
  • Interface : Application Python Kivy + Web Dashboard
  • Langue de programmation : Python, C++ (Arduino IDE)

✨ Caractéristiques Principales

Contrôle WiFi

Commande à distance en temps réel via WiFi

Retour Vidéo

Flux vidéo continu de la caméra embarquée

Navigation

Détection et évitement d'obstacles autonome

Application Mobile

Interface Kivy pour Android et PC
